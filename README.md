## تجربة الموقع على جهازك
1. فك ضغط ملف ZIP.
2. افتح مجلد المشروع.
3. افتح `index.html` في المتصفح.

## النشر المجاني على Vercel
1. فك ضغط ملف ZIP على جهازك.
2. سجّل الدخول إلى Vercel.
3. من لوحة التحكم اختر **Add New → Project**.
4. ارفع المجلد عبر GitHub (أنشئ مستودعًا جديدًا وارفع الملفات الثلاثة) ثم اربطه بـ Vercel.
5. اترك إعدادات البناء الافتراضية لموقع HTML ثابت، ثم اضغط **Deploy**.
6. بعد انتهاء النشر سيظهر لك رابط عام مجاني من Vercel.

لا توجد أوامر بناء مطلوبة؛ الملف `index.html` هو الصفحة الرئيسية.
